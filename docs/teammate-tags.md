# 队友画像标签规范（海克斯大乱斗）

面向 `league-soraka` 的「队友画像」功能。目标是选人阶段给 5 名队友各贴 2–3 个玩法标签 + 1 个数据质量标签，并附证据数字。所有数据只在本机读取，不上传、不发聊天。

## 1. 数据源

| 来源 | 用途 | 限制 |
| --- | --- | --- |
| LCU `/lol-champ-select/v1/session` | 5 名队友的 puuid、英雄、`nameVisibilityType` | 匿名/隐藏时可能没有真 puuid |
| SGP `/match-history-query/.../SUMMARY` | **首选**：一次返回 20 场，每项的 `json` 是完整 10 人 | 需要 `entitlements` 令牌（Akari 同款） |
| LCU `/lol-match-history/v1/products/lol/{puuid}/matches` | SGP 失败时的列表兜底 | 对“别人”只返回他自己那一条 participant |
| LCU `/lol-match-history/v1/games/{gameId}` | 单局 10 人详情兜底 | 实测腾讯服返回 10 人 |
| SGP `/match-history-query/.../DETAILS` | 单局详情兜底 | 产品 id 可能需要 `平台_游戏id` 前缀 |

数据获取顺序：

```
SGP SUMMARY（20 场，每场 10 人 + 伤害/承伤/出装/强化）
  → LCU 列表 + LCU 单局详情
  → SGP DETAILS（最多 10 局/人）
  → 仅本人 participant（速率版，低置信）
```

实测：5 人并发约 **2.1 秒**；SGP SUMMARY 的 `metadata.private` 可直接判断隐藏生涯。

SGP 不是隐私绕过：`privacy=PRIVATE` 的玩家可能被 403/空结果挡住；如果某区服仍返回数据，就照常算标签并加「生涯隐藏」注记。

## 2. 采样规则

- SGP 一次拉最近 20 场；筛 `mapId=12`、`queueId∈{2400,450}`、时长 ≥5 分钟、排除重开/早退。
- 取最近 20 场；显示时间跨度（例如 `9/20–11/9`）。
- 最新一场 >30 天：标「久未上线」，置信度降一档；跨度 >90 天：标「样本偏旧」。
- 每局等权，暂不做时间衰减。
- 5 人并发（5 个 worker），单请求 8 秒，整体 12 秒 deadline；缓存 30 分钟，单局缓存 24 小时。

### 能贴什么

| 样本 n（ARAM 场次） | 能贴的标签 | 置信度 |
| --- | --- | --- |
| ≥12 | 全部 | 高 |
| 8–11 | 全部；负面/调侃标签需 ≥50% 场次命中 | 中 |
| 5–7 | 正面/中性 + 稳定类 + 节奏类；负面/调侃标签不贴 | 低 |
| <5 | 只贴数据质量（匿名者/隐藏生涯/数据暂不可用/非大乱斗/样本不足/新号） | — |

### 命中率

- 行为类：聚合指标过线，**且逐局命中率**达标。
  - 正面/中性：n≥5 且 ≥40%（5 场 2 场、8 场 4 场、10 场 4 场）。
  - 负面/调侃：n≥8 且 ≥50%（8 场 4 场、10 场 5 场、12 场 6 场）。
- 稳定类：按比例，如心之钢 ≥50%（5 场 3 场、8 场 4 场）。
- 极端类：挂机嫌疑 n≥3 且 ≥2/3 场，低置信，只提示不判定。
- 节奏类：最近 5 场/24h，不受 8 场限制；文案写“最近 5 场全负”，不写“惯犯”。
- 每个标签显示 `x/n 场`。

## 3. 指标

| 指标 | 定义 |
| --- | --- |
| 伤害占比 | 对英雄伤害 / 同队 5 人对英雄伤害 |
| 承伤占比 | 总承伤 / 同队总承伤 |
| 击杀/助攻/死亡占比 | 各自 / 同队总数 |
| 金币占比 | 金币 / 同队总金币 |
| 治疗/CC 占比 | 治疗或 `totalTimeCrowdControlDealt` / 同队总数 |
| 参团 | (击杀 + 助攻) / 同队总击杀 |
| 伤害/击杀 | 对英雄伤害 / max(1, 击杀) |
| 各“/分” | 数值 / 分钟 |
| 心之钢率 / 坦克装率 | 含 3084 / 含 ≥3 件坦克装的场次比例 |
| 收集者率 | 射手/战士/刺客英雄场次中，出 6676「收集者」的比例 |
| 暴击几率 | 最后出装暴击装（`data/items.json`）+ 前三个增幅的暴击率加成 |
| 强化平均分 | 每局非零 `playerAugment1..6` 在 `stats.byChampion[英雄][增幅]` 的 performance 均值 |
| 场次/连胜/连败/夜间率 | 按 `gameCreation` 排序统计 |

占比类取中位数；胜率取计数；速率类取分钟均值。没有同队数据时，占比类标签跳过或改用速率阈值，置信度降为低。

## 4. 标签全表

> 默认行为类 n≥5、负面 n≥8；稳定类/节奏类 5–7 场可低置信展示；n<5 只出数据质量。

### 输出

- **大爹**（正面）：伤害占比 ≥30%，胜率 ≥50%；逐局伤害占比 ≥28% 且该局获胜才算命中（≥50%）。
- 用户可在本地「标签调参」后台（`标签管理.cmd`）修改所有标签的阈值、命中率、样本数和启用状态。
- **隐形大爹**（正面）：伤害占比 ≥24%，击杀占比 ≤20%，助攻占比 ≥20%。
- **玻璃大炮**：伤害占比 ≥24%，死亡占比 ≥26%（或死亡/分 ≥0.55）。
- **刮痧师傅**（调侃）：法师/射手/刺客（非辅助）≥55%，伤害占比 ≤16%，金币占比 ≥15%。

### 人头

- **人头狗**（调侃）：击杀/分 ≥0.45，且（击杀占比−伤害占比 ≥10% 或 伤害/击杀 ≤3200），助攻占比 ≤20%；n≥8 且 ≥60% 命中。
- **让头菩萨**（正面）：助攻占比 ≥30%，击杀占比 ≤15%，伤害占比 ≥18%。

### 坦克/承伤

- **城墙**（正面）：坦克职业 ≥35% 或 坦克装 ≥3 件 ≥45%；承伤占比 ≥24%；死亡/分 ≤0.55；≥40% 命中。
- **心之钢信徒**：心之钢（3084）≥50%；承伤/分 ≥1500。
- **敢死队**：承伤占比 ≥22%，死亡占比 ≥24%。
- **开团机器**（正面）：CC 占比 ≥25%，承伤占比 ≥20%，死亡/分 ≥0.40。
- **纸糊前排**（调侃）：坦克职业 ≥45%，承伤占比 ≤20%，死亡/分 ≥0.45。
- **后排坦克**（调侃）：坦克职业 ≥45%，伤害占比 ≥22%，承伤占比 ≤20%。

### 辅助/团队

- **移动泉水**（正面）：治疗占比 ≥28%，治疗/分 ≥600。
- **罚站王**（正面）：CC 占比 ≥30%。

### 死亡/存在感

- **提款机**（调侃）：死亡占比 ≥26%，参团 ≤45%；n≥8 且 ≥50% 命中。
- **敢死队长**：死亡/分 ≥0.65，伤害占比 ≥22%。
- **隐身哥**（调侃）：伤害占比 ≤13%，承伤占比 ≤15%，参团 ≤35%。
- **挂机嫌疑**（低置信）：伤害占比 ≤4%，金币/分 ≤180，n≥3 且 ≥2/3 场。
- **保KDA**（调侃）：死亡/分 ≤0.25，参团 ≤40%，伤害占比 ≤17%。
- **落地成盒**：最长存活中位数 ≤55 秒。

### 英雄池

- **绝活哥**（正面）：单一英雄 ≥35%，且该英雄胜率 ≥50%。
- **英雄海**（中性）：独特英雄 ≥80%，n≥10。

### 心态/节奏

- **连败战神**（调侃）：最近 5 场全负，且 24h 内 ≥4 场。
- **连胜王**（正面）：最近 ≥3 连胜。
- **深夜战士**：≥40% 场次在 00:00–05:00。
- **肝帝**：24h 内 ≥8 场。
- **状态低迷**（中性）：最近 10 场胜率 ≤35%，伤害占比 ≤18%，死亡/分 ≥0.55。

### 海克斯专属

- **天选之人**（正面）：强化平均 `performance` ≥82。
- **赌狗**（调侃）：强化平均 `performance` ≤78。

## 5. 数据质量状态机

| reason | 触发 | 显示 | 贴玩法标签 |
| --- | --- | --- | --- |
| `anonymous` | `nameVisibilityType=HIDDEN` / `obfuscatedPuuid` / puuid 全 0 | 神秘人 · 匿名者 | 否 |
| `private` | `privacy=PRIVATE`，SGP 403/空 | 神秘人 · 隐藏生涯 | 否；若 SGP 仍返回数据则照常贴 + 注记 |
| `unavailable` | SGP/LCU 401/403/429/超时/跨区 | 数据暂不可用（可重试） | 否 |
| `no_aram` | 最近 30 场 ARAM <3 | 非大乱斗玩家 | 否 |
| `low_sample` | ARAM 3–4 场 | 样本不足 | 只贴稳定类，低置信 |
| `new_account` | 等级 ≤50 或 ARAM 总场次 <20 | 新号/小号 | 只贴数据质量 |

只要 SGP 对某个真 puuid 返回了数据，就不显示「神秘人」；`unavailable` 也不叫神秘人。

## 6. 规则形状

规则在 `overlay-py/tagrules.py`，纯函数，支持 `all/any/not` 与 `>= <= > < ==`。示例：

```json
{
  "id": "kill_hog",
  "family": "kills",
  "name": { "roast": "人头狗", "neutral": "收头位" },
  "tone": "roast",
  "kind": "behavior",
  "priority": 88,
  "min_games": 10,
  "min_hit_rate": 0.6,
  "excludes": ["generous", "carry"],
  "when": { "all": [
    { "metric": "killsPerMin", "op": ">=", "value": 0.45 },
    { "any": [
      { "metric": "killShareMinusDamageShare", "op": ">=", "value": 0.10 },
      { "metric": "damagePerKill", "op": "<=", "value": 3500 }
    ]},
    { "metric": "assistShare", "op": "<=", "value": 0.18 }
  ]},
  "per_game": "same",
  "evidence": "击杀占比 {killShare:.0%} · 伤害占比 {dmgShare:.0%} · 伤害/击杀 {dmgPerKill:.0f} · {hits}/{n} 场"
}
```

冲突：大爹 ↔ 隐身/刮痧；城墙 ↔ 纸糊前排/后排坦克；提款机 ↔ 敢死队长；人头狗 ↔ 让头菩萨；保KDA ↔ 敢死队长。同族最多 1 个，总数 3 个玩法标签 + 1 个数据标签。

## 7. 使用

```bash
python scripts/teammates-cli.py            # 当前选人 5 人
python scripts/teammates-cli.py --demo     # 无客户端样例
python scripts/teammates-cli.py --json
python scripts/teammates-cli.py --stats    # 打印指标，校准阈值
python scripts/teammates-cli.py --probe    # 只验证数据源
python scripts/teammates-cli.py --clear-cache
```

选人界面点索拉卡胶囊，面板底部会出现「队友画像」块；分析中先显示占位，2–4 秒内替换。

### 7.1 选人预取（不自动弹窗）

- 进入 ARAM 选人后，浮层每 1.5 秒探测 `gameflow-phase`；`ChampSelect` + 5 人齐 + 英雄齐 + ARAM bench 门控后，后台预取一次。
- 预取只写 `_prefetched_*` 状态，不渲染、不弹窗；胶囊是唯一入口。
- 点胶囊时：有预取 → `_show_prefetched()` 同步渲染（0.3 秒内）；预取中 → 先显示“选人分析中…”，行到后自动出；无预取 → 现有手动路径。
- 离开选人清空预取；同一局只预取一次；右键收起不丢预取，再点仍秒开。
- 配置：`data/config.json` 的 `prefetch_champ_select`（默认 true）、`prefetch_champ_select_all_modes`（默认 false）；临时关闭 `--no-prefetch-champ`。

## 8. 限制

- 标签是最近 20 场的行为倾向，不是人格/技术定论。
- 隐藏生涯、匿名、跨区、SGP 超时都可能查不到；按第 5 节显示原因，不硬编。
- 阈值是初值，用 `--stats` 和真实对局校准。
- 只读客户端数据，不注入、不读内存、不模拟点击；Riot/腾讯不背书。
